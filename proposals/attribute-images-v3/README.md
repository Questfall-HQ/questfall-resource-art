# Refined attribute images v3

Two transparent PNG edits generated with the built-in image generation tool
from the v2 Mining and Crafting files. The selected edits now live in
`assets/attributes/`; older v2 images remain here for comparison.

| File | Edit direction |
| --- | --- |
| `assets/attributes/mining.png` | Preserve the salmon pickaxe head, pose, scale, and satin style; change only the near-black handle and end cap to light warm silver-gray with a muted pink tint, so the full silhouette reads on dark UI at 16–24 px. |
| `assets/attributes/crafting.png` | Preserve the pale-blue anvil and quiet shading; make the central body and base taller and fuller so the silhouette occupies about 82–85% of the square canvas height and reads at 16–24 px. |

Both prompts required a transparent square canvas, clean alpha edges, no extra
objects or text, no cast shadow, and restrained highlights. Crafting needed a
second edit pass to reach the intended height.
