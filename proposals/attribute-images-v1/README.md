# Attribute image proposal v1

Six transparent PNG concepts generated with the built-in image generation tool.
These are preview candidates, not the active Application or Admin attribute art.

Each image uses its existing SVG silhouette as the subject reference. Mining
Power uses a diagonal pickaxe in violet steel, deliberately distinct from the
gold lightning used for the Mining Points resource. The Mining Points image was
a finish and lighting reference for the first pickaxe, not a shape reference.
The subsequent five images used the new pickaxe as their shared finish reference.

Common prompt constraints: a single centered UI object on a genuinely
transparent square canvas; polished semi-3D enamel and metal; crisp silhouette
at 16–32 px; no badge, tile, text, numerals, sparkles, extra objects, or
watermark. Preserve the approximate pose and recognition of each original SVG.

the active icons until the candidates have been reviewed at actual UI sizes.
