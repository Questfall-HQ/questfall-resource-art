# Attribute image proposal v2

Six transparent PNG concepts generated with the built-in image generation
tool, using each v1 image as an edit target and its original SVG silhouette as
a shape reference. Application now uses these six images as its attribute icons;
Admin continues to show them beside the original SVGs.

Shared prompt: preserve one centered, recognizable attribute silhouette on a
transparent square canvas with mild depth; replace glossy chrome and neon rims
with calm satin or matte shading, broad color masses, and very few soft
highlights. Keep the image readable at 16–32 px, without badges, backgrounds,
text, sparkles, or extra objects.

| File | v2 direction | Attribute color |
| --- | --- | --- |
| `inventory.png` | Quiet lilac cube with gentle side shading | `#c4b5fd` |
| `mining.png` | Salmon pickaxe with a dark slate handle | `#fca5a5` |
| `crafting.png` | Pale blue anvil with restrained edges | `#93c5fd` |
| `trading.png` | Cool silver-blue pouch with a simple dark knot, no green or gold | `#cbd5e1` |
| `stamina.png` | Golden yellow heart with a broad amber ECG groove | `#FFD166` |
| `luck.png` | Single four-leaf mint clover with a short stem, no metal rim | `#86efac` |

Mining Power remains the pickaxe attribute. Mining Points remains the separate
gold lightning resource.
